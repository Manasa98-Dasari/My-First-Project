# Used Car Price Analysis in India
**End-to-End Data Analytics Project | Python | Excel | Power BI**

---

## 📌 Project Overview
This project focuses on analyzing used car prices in India to understand how factors such as **brand, model year, fuel type, transmission, mileage, and location** affect resale value.  
The objective is to help **buyers, sellers, and dealers** make data-driven pricing decisions.

The project follows a complete **data analytics lifecycle**:
Data Collection → Data Cleaning → Exploratory Data Analysis → Visualization → Insights.

---

## 🎯 Business Problem
Used car prices vary significantly across regions and brands. Without proper analysis, buyers may overpay and sellers may undervalue vehicles.  
This project aims to uncover **pricing patterns and key influencing factors** using real-world data.

## ⚙️ Project Workflow
1. **Data Collection**
   - Extracted used car listings using Python and BeautifulSoup.
   - Collected attributes such as price, brand, year, fuel type, mileage, and city.

2. **Data Cleaning & Transformation**
   - Removed duplicates and handled missing values.
   - Standardized formats using Pandas and NumPy.
   - Prepared clean datasets for analysis and visualization.

3. **Exploratory Data Analysis (EDA)**
   - Analyzed price distribution by brand, fuel type, and year.
   - Identified trends and outliers affecting resale prices.

4. **Visualization & Reporting**
   - Built interactive dashboards in Power BI.
   - Highlighted key KPIs and trends for decision-making.

---

## 📊 Key Insights
- Popular brands like **Hyundai, Maruti, and Toyota** show higher resale consistency.
- **Newer vehicles** retain more value compared to older models.
- **Diesel cars** dominate older listings, while petrol cars are more common in recent years.
- Location plays a major role in price variation.
